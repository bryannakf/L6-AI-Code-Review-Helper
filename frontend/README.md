# Frontend

This frontend is a Vite + React app for submitting code snippets to the backend review API.

## Available scripts

- `npm install` — install dependencies
- `npm run dev` — start the Vite dev server
- `npm run build` — create a production build
- `npm test` — run the frontend test suite

## Notes

The app communicates with the backend at `/api/review` and renders the review result card used by the AI review helper.
